# Magic Eraser // Notes

> Where Magic Eraser departs from the Gogo1951 add-on Style Guide, kept so no review raises it again.

## Exceptions

### Shared Default profile

- **Departs from:** SAVED VARIABLES, The Two Models, the selection rule.
- **Instead:** Every character shares one Default profile holding every setting, and each character's own lists live in AceDB's char scope, outside the profile.
- **Why:** A setting changed once applies on every character, while a character's lists stay with that character whatever profile is active.

### Mini-map screenshot in Tips & Tricks

- **Departs from:** README generation, Image Handling, images in the feature blocks and nowhere else.
- **Instead:** The README keeps the mini-map tooltip screenshot under Tips & Tricks, Mini-Map Button, beside its click table.
- **Why:** The tooltip is where every click in that table shows its result, so the screenshot works as the table's picture rather than a feature's.

### Color picker beside its switch

- **Departs from:** Build Reference, OPTIONS PANEL, Sub-Option Rows, a switch with exactly one setting of its own.
- **Instead:** A switch whose one setting is a color picker shares its line with the picker as two equal halves, the picker keeping its own caption and hiding while the switch is off.
- **Why:** A color swatch draws its caption beside itself, so it reads as a labeled control in its own right rather than a value for the switch's caption.
